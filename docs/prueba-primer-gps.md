# Checklist del primer Teltonika FMC920 LATAM

**No enviar ubicaciones sin autorización del propietario o conductor.**

## Antes de encender
1. Verificar modelo exacto en etiqueta, IMEI y bandas LTE con el operador elegido en Ecuador.
2. Obtener SIM con plan de datos y APN confirmado; desactivar PIN de SIM si el manual del equipo lo requiere.
3. Tener VPS y Traccar instalados y accesibles por la dirección/puerto del protocolo del FMC920.
4. Configurar APN, servidor, puerto y parámetros del equipo según el manual oficial del firmware.
5. Registrar el identificador del dispositivo en Traccar de manera privada; nunca publicarlo en GitHub.

## Pruebas
- [ ] Alimentación y estado de LEDs según manual
- [ ] SIM registrada y datos móviles activos
- [ ] Primer mensaje recibido por Traccar
- [ ] Coordenadas correctas y hora UTC
- [ ] Vehículo propio estacionado y luego recorrido de prueba consentido
- [ ] Historial y reconexión después de pérdida temporal de señal
- [ ] Alertas de velocidad y desconexión, evitando falsas alarmas
- [ ] Permisos de acceso y datos protegidos por HTTPS
- [ ] Consumo de datos, costo y estabilidad durante 24 horas
